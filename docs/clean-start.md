# Проверка чистого запуска — 06.1

6 ноября 2026 года проверена чистая копия коммита `097d53c`, без node_modules, сгенерированного клиента и пользовательского .env. Использованы Bun 1.4.0, Docker 29.5.2 и отдельный Compose-проект `campusride-061`. Основная база проекта не изменялась.

## Результаты

- `cp .env.example .env` и `bun install --frozen-lockfile`: успешно, lockfile не требует обновления.
- `bun run db:generate` и `bun run db:validate`: успешно.
- Новая PostgreSQL: успешно применены обе миграции (initial и demo_payments).
- Seed и его повтор: три аккаунта, пять районов, три корпуса, семь точек. Повтор сохраняет существующие записи.
- `docker compose up --build -d`: образы API и web собираются; API запускается после готовности БД, web — после готовности API.
- Для повторной проверки исключительно тестовый том был пересоздан. На пустой базе миграции выполнены уже командой запуска контейнера API, затем выполнен seed внутри контейнера.

Для изоляции использован временный override: порты БД/API/web — 15432/13001/15173, WEB_ORIGIN — http://localhost:15173. Внутренние порты и адрес прокси сохранены. Обычная установка использует 5432/3001/5173 и команды README.

## Исправления инструкции

В обе последовательности запуска добавлен seed: миграции создают схему, но не демо-аккаунты и справочники. Удалено устаревшее описание кнопки проверки подключения; указаны действующие адреса health и Swagger. Seed не создаёт поездки: водитель добавляет автомобиль и публикует поездку через интерфейс.

Проверка контейнеров относится к локальному демонстрационному режиму с Vite preview и HTTP. Перед запуском на стандартных портах следует остановить другие экземпляры приложений. Не удаляйте основной том PostgreSQL ради повторения проверки.

HTTP: интерфейс, readiness, Swagger, OpenAPI JSON и точки маршрута вернули 200. Вход и последующий GET /api/auth/me проверены для каждой из трёх ролей с независимым cookie-хранилищем: 200.
