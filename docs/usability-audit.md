# Адаптивность и удобство — 05.6

Проверено 5 ноября 2026 года в браузере на локальном Vite + NestJS, с демо-аккаунтами водителя и администратора.

## Выполненные проверки

- На ширине 360 px: поиск, главные пассажира и водителя, профиль, автомобили, поездки, создание поездки, оба списка заявок, уведомления, отзывы и история. Заголовки соответствуют маршрутам, ошибок загрузки после запуска API нет; ширина документа равна ширине окна.
- На ширине 1440 px: те же основные разделы водителя и общие экраны. Горизонтального переполнения нет.
- Администрирование, пользователи, модерация и история решений проверены на обеих ширинах: ширина документа 360/1440 px соответственно.
- В заголовок истории временно подставлена длинная строка без пробелов: на мобильной ширине переполнения нет. Данные в БД не менялись.
- Добавлена первая клавиатурная ссылка «Перейти к содержимому»: Enter переводит фокус на main, сохраняя маршрут. Это проверено регрессионным тестом React. Ссылки имеют общий видимый контур фокуса; основной контент переносит длинные строки, поля ограничены шириной контейнера.
- Существующие тесты проверяют ошибки сети, повтор загрузки, истечение сессии и ошибки форм. При первоначальном запуске до готовности API браузер показал понятное сообщение об ошибке; после перезагрузки разделы загрузились.

## Демо-данные и готовность

Демо-аккаунты водителя и администратора успешно проходят вход; у водителя доступны обе роли. Имена и принадлежность к УрФУ осмысленны. Справочники и публичные поездки доступны через API. Seed сохраняет пользовательские изменения и не сбрасывает существующие аккаунты. Источники адресов и правила повторного наполнения описаны в [демо-данных](demo-data.md).

Общая проверка `bun run check`: 651 тест API и 271 тест интерфейса, проверка схемы Prisma, форматирование, lint, типы и сборка прошли. Проверка размеров выполнена на текущих демо-данных и не заменяет финальную репетицию полного сценария с двумя сессиями. Перед защитой следует убедиться, что опубликованные поездки имеют будущую дату, и пройти сценарии по [инструкции жизненного цикла](demo-lifecycle.md) и [администрированию](demo-admin.md).
